# PAPERPLANES :airplane:
_Paperplanes_ is a Unreal Engine game made for _ThatGameCompany_ gamejam#2 on Nov 2026. In it you are a little paper airplane flying around, communicating with others, liberating them, making join your "flock", and do tricks in the air! With no particular objecive, I focused a lot on camera, character, and control so basically making a game that feels extremely good to fly around with others.

Play it at https://jstriedinger.itch.io/paperplanes
